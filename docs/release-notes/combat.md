# Combat development build

- Craft and carry a service rifle; V draws/holsters, LMB or Space fires toward the cursor.
- Physical pack ammunition, missed shots, firing cooldowns, health regeneration, and protected retreat.
- Signal scouts, dismantlers, and armored haulers, with distinct silhouettes and roles tied to the old enchanted network.
- Gradual enemy introductions, three eastern arrival gates in later waves, and bounded weighted obstacle routing.
- Piercing cannons for armor; pulse turrets for group damage and slowing; assembler/inserter resupply for every turret.
- Orange melee telegraphs, armor/health descriptions, rifle crosshair, turret range rings, hit feedback, and wave composition previews.
- Expanded Oren/Ada dialogue explains the construct threat.
- Validated saves include attack windups, slows, turret cooldowns, and engineer combat state; older active waves migrate safely.

Waves remain voluntary and normal new games remain empty. The prepared sandbox uses a separate save slot: run Godot with --script res://tests/play_defense.gd. See docs/defense.md for controls and details.
