# Ironworks v0.10.0 — Oldbridge Renewal

Download the Windows x86-64 ZIP, extract the entire folder, and run Ironworks.exe. Godot is not required. SHA256SUMS.txt verifies the download.

## New in this build

- Modernized workspaces, technology progression, settlement cards, inventory previews, contextual machine reports, notification history, and a quieter animated HUD.
- Renewable managed forestry: camps harvest trees over several cycles, then replant after the shelter unlock. Growth stages, grove coverage and recovery status explain sustainable timber production.
- Hand-crafting queues missing intermediate ingredients in sequence.
- An optional personal cottage with a private furnished interior and decorative choices.
- A Homecoming chapter connecting regional production, town restoration and settlement rewards.
- Stronger regional identity and the Reedwater Marsh causeway/lodge restoration prototype.
- Expanded opt-in combat briefings, authored encounters, clearer rewards and supply costs, weapon sidegrades and battlefield feedback.
- Textured terrain, bounded warm lighting, shared shadows, richer furnace/tree/player/Town Hall artwork and batched furnace rendering.
- Material-aware furnace and Town Hall surfaces, soft local-light blocking by stone walls and repaired civic buildings, and an optional simpler lighting mode.
- Lumber-camp interaction and layout stability fixes, plus clearer progression and machine information.

## Save compatibility

Start a new world. This development release supports the current v3 save schema only; older saves are not converted. Existing old save files remain on disk. Current saves retain validation, backups, named slots and optional autosaves.

## Playtest notes

Combat remains opt-in at the Town Hall beacon. This is an unsigned Windows prototype. Large factories at 4K can still be slow: use a smaller window and disable Detailed surface lighting under Pause → Presentation if needed. G4–G6 graphics work and later regional/combat roadmap items remain planned.
