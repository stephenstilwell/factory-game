First Windows playable prerelease of Ironworks / Frontier.

Rebuild Oldbridge from an empty inventory: mine finite seeded deposits, automate production, restore civic landmarks, earn trade income, improve your engineer, and prepare for voluntary beacon defense waves.

Download the Windows ZIP below, extract the entire folder, and run `Ironworks.exe`. Keep the game pack and graphics libraries together. Godot is not required. Controls and save instructions are included in `README.txt`.

This is an early prototype with two research technologies, three trainable skills, and ten defense waves. Power networks and multiplayer are not implemented. The executable is unsigned.

The repository is private, so downloads are available only to people with repository access.
